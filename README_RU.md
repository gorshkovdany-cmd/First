# ДАЛЬНИЙ РЕЙС — русская версия 1.0 для PSP

Оригинальный автономный 3D-симулятор дальнобойщика для PSP-3000/3008, написанный на C и PSPSDK. Игра не содержит моделей, фирменных знаков и материалов Euro Truck Simulator.

## Возможности игрового релиза 1.0

- Безэкранная смена секторов процедурного мира: дороги, перекрестки, холмы, деревни, склады, контейнерные площадки, знаки, фонари, заправки, деревья. Это стилизованная низкополигональная карта, а не фотореалистичная Европа.
- Три самостоятельных тягача («СЕВЕР 18», «ТАЙГА 26», «АТЛАНТ 34») с покупкой за заработанные деньги; полуприцеп с ограниченной кинематикой.
- Бесконечные заказы на перевозку груза, расстояние рейсов 9–18 км по дорожной сети, деньги за выгрузку, погрузка/разгрузка, заправка и ремонт.
- 22 автомобиля в потоке. Простые AI-модели едут по полосам и уменьшают скорость перед участником движения; удар может повредить тягач.
- Физика с инерцией, различной массой груза, дорожным сцеплением, наклоном дороги, аэродинамическим сопротивлением, ограничением мощности двигателей, плавным откликом педали, автоматической коробкой, тормозом, реверсом, дизельным расходом и повреждениями.
- Псевдослучайная перемена освещенности, GPS с указанием очередной точки, две камеры (снаружи / кабина), процедурно синтезированный звук мотора, пауза, экран информации о рейсе.
- Русский интерфейс, кириллический растровый шрифт, русские подсказки и названия тягачей. Сохранения на карту памяти с контрольной суммой и двумя поколениями (`SAVE.DAT` и `SAVE.DAT.BAK`). Предыдущие сохранения версии 0.1 совместимы по формату.

**Важно:** версия 1.0 означает самостоятельный игровой релиз указанного функционала, не эквивалент ПК Euro Truck Simulator по объему, текстурам и физике. На физической PSP не измерены FPS, время автономной работы и устойчивость. Поскольку за реальную консоль отвечает пользователь, это не является обещанием абсолютной безопасности.

## Установка (карта памяти PSP)

1. На консоли должна быть предусмотрена поддержка самодельных программ (homebrew): например, совместимая ARK-4. Игра **не изменяет прошивку** и сама не устанавливает CFW.
2. Распакуй `ROAD_HAUL_PSP_1_0_Install.zip` в корень Memory Stick. Итоговый файл: `PSP/GAME/ROADHAUL/EBOOT.PBP`.
3. В меню PSP выбери «Игра → Memory Stick → ДАЛЬНИЙ РЕЙС 1.0».
4. Для защиты существующих файлов сначала сделай резервную копию карты, затем попробуй игру на PPSSPP.

## Управление

| Кнопка | Функция |
|---|---|
| Аналоговый стик | Руление |
| ✕ | Газ |
| □ | Тормоз, нажать после остановки для выбора заднего хода |
| ○ | Загрузка/выгрузка или заправка/ремонт рядом с терминалом при остановке |
| △ | Вид сзади / из кабины |
| ↑ | Следующий тягач / покупка у склада |
| ↓ | Стояночный тормоз |
| L, R | Оглядеться |
| SELECT | Карта/параметры доставки |
| START | Пауза и подсказка по управлению |

Начальная точка — на подъезде к складу; подъедь к подсвеченной зоне и нажми ○ для загрузки, а затем следуй GPS через дорожную сеть до места выгрузки. Заправки находятся у узлов дорог. Машина ограничена 90 км/ч.

## Сборка и проверка

Проект собирается с PSPDEV (рекомендуемый Docker-образ `pspdev/pspdev:v20261001`). Из папки проекта: `./build_mac.sh` при установленном Docker Desktop или `make` внутри PSPDEV.

Проверки на Linux/macOS: `./tests/run_tests.sh`, `./tests/run_render_tests.sh`, `./tests/run_stress.sh`, `./tests/safety_audit.sh`.

Для точной проверки собственной PSP желательно отдельно испытать в PPSSPP обе камеры, стартовый заказ, заправку, сохранение после перезапуска и смену фур. Автоматические тесты геометрии **не являются** визуальной проверкой рендеринга PSP GPU.

## Ограничения

Дороги пока представляют ортогональную сеть; нет реальных карт Европы, высокодетализированных текстур, фотореалистичных салонов, сложных перекрестков с полноценной системой уступания дороги, физики шин промышленного симулятора и повреждений кузова. Звук синтезируется из частоты вращения двигателя и не использует записи реальных грузовиков. Статус релиза основывается на успешной PSPDEV-компиляции и автоматических тестах. Реальное изображение и производительность нужно подтверждать через PPSSPP и PSP, а не по иллюстрациям.

## Полная русификация

Все игровые надписи, уведомления, название в меню PSP, управление, тексты навигации, экран заказа, названия тягачей и заставка переведены на русский язык. В игре встроены собственные растровые кириллические символы, включая Ё/ё, поэтому внешний файл шрифта не нужен. Технический путь `PSP/GAME/ROADHAUL` оставлен прежним для совместимости с сохранениями версии 1.0.

**Безопасность:** изменялись только игровые строки, встроенная таблица символов и оформление иконки. Код работы с системной Flash, прошивкой и NAND не добавлялся. Однако поведение не испытано на реальном устройстве и не может считаться гарантированно безопасным.
